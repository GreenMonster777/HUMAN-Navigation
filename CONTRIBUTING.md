# Contributing

Help make interfaces easier to use for real people, with different hand sizes, mobility, dexterity, and assistive technologies.

- Prefer simple and measurable improvements over visual decoration.
- Include the problem being solved, reproduction steps, and how you tested a change.
- Preserve accessible fallback navigation when changing swipe behavior.
- Do not silently enable camera, microphone, location, analytics, or network communication.
- Treat critiques as engineering input. Show evidence when making performance or accessibility claims.
- Do not add third-party code without checking licensing and attribution.

Code-of-conduct and maintainer contact policies can be added before opening public contributions.
